## Data

All series are monthly, seasonally adjusted, from FRED (Federal Reserve Bank of St. Louis),
downloaded with `pandas-datareader`. The raw download is saved in `data/raw/` and fixed at data
through August 2026.

| Series | FRED ID | Link |
|---|---|---|
| CPI-U: All items (headline) | CPIAUCSL | https://fred.stlouisfed.org/series/CPIAUCSL |
| CPI-U: All items less food and energy (core) | CPILFESL | https://fred.stlouisfed.org/series/CPILFESL |
| PCE chain-type price index | PCEPI | https://fred.stlouisfed.org/series/PCEPI |
| CPI-U: Food at home | CUSR0000SAF11 | https://fred.stlouisfed.org/series/CUSR0000SAF11 |
| CPI-U: Energy | CPIENGSL | https://fred.stlouisfed.org/series/CPIENGSL |
| CPI-U: Energy services | CUSR0000SEHF | https://fred.stlouisfed.org/series/CUSR0000SEHF |
| CPI-U: Gasoline (all types) | CUSR0000SETB01 | https://fred.stlouisfed.org/series/CUSR0000SETB01 |
| CPI-U: Electricity | CUSR0000SEHF01 | https://fred.stlouisfed.org/series/CUSR0000SEHF01 |

The raw file also contains CPI-U: Food (CPIUFDSL), which was downloaded for the data memo but is
not used in the analysis. No API key is needed. October 2025 CPI was not published (government
shutdown); see `data/raw/fred_prices_raw_README.txt`.

## Software

Python 3.13.7. Libraries and versions are in `requirements.txt`:

```bash
pip install -r requirements.txt
```

## Replication

*(To write: which notebooks to run, in what order, and what each produces.)*

- `code/data_memo.ipynb`: data download / loading, inflation, summary statistics and unit-root
  tests. Writes `data/clean/inflation_annualized.csv` and the figures and tables in `output/`.
- `code/fit_<series>.ipynb`: model fitting for one series.
- `code/pipeline.py`: functions the notebooks call.

## Folder structure

```
data/raw/         FRED download, exactly as retrieved (+ README on the series)
data/clean/       annualized monthly inflation
code/             notebooks and pipeline.py
output/           figures and tables generated by the code
paper/            the submitted paper (PDF)
dashboard/        Quarto dashboard source
```
